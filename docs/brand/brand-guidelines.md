# ANTS — Guía de marca

Decisiones finales de identidad visual, validadas el 2026-06-22 durante la sesión de brainstorming de la landing page. Usar este documento como referencia para redes sociales, papelería, merch o cualquier pieza futura — no solo para el sitio web.

## Mantra

> "Creamos sistemas de venta inteligentes con tecnología IA, diseño profesional y psicología cognitiva."

## Concepto de marca

ANTS = "Camino de Hormigas". Una hormiga sola no construye nada; miles coordinadas mueven montañas. Esa es la promesa del negocio: no tácticas sueltas, sino sistemas coordinados (IA + diseño + psicología) que trabajan juntos.

Dirección visual elegida: **street art / graffiti bubble-letter**, partiendo del arte original (`Logo_street_art.png` — mural con letras burbuja, contorno negro grueso, badge circular). Se descartó la dirección inicial "Miami Vice geométrico/neón" en favor de esta, por pedido explícito del usuario tras ver que no conectaba con la pieza de street art ya existente.

## Logo

- **Estilo**: bubble-letter / graffiti urbano. Letras redondeadas, contorno negro grueso (~3-4px en proporción), sombra tipo "sticker" (capas de offset sólido, no blur).
- **Tratamiento de color elegido**: **letras alternadas** — A y T en lila, N y S en menta (o el patrón equivalente sobre la palabra completa) — sobre **badge circular amarillo** (el amarillo del mural original se conserva).
- **Antena**: se conserva el detalle de dos antenas/puntos sobre la "A", herencia del logo original en blanco y negro (`protologo3.png`).
- **Versión de producción pendiente**: la exploración en el companion visual usó la web font "Luckiest Guy" + CSS como aproximación rápida de dirección. El asset final para el sitio y redes debe vectorizarse a mano (SVG curado) tomando como referencia real `Logo_street_art.png`, no quedarse en la versión con font genérica. Tratarlo como tarea de implementación, no como diseño cerrado.
- **Logo original en B/N** (`protologo3.png`) queda como variante de respaldo para contextos donde el color no aplique (ej. sellos, watermarks, documentos).

## Paleta de colores

| Uso | Color | Hex |
|---|---|---|
| Letra A / T (logo) | Lila | `#C4B5FD` |
| Letra N / S (logo) | Menta | `#5EEAD4` |
| Badge / acento principal | Amarillo (heredado del mural) | `#FFD60A` |
| Contorno / sombra | Negro tinta | `#1A1A2E` |
| Fondo general del sitio | Off-white | `#FAFAFC` |
| Superficie / cards | Blanco | `#FFFFFF` |
| Texto principal | Negro tinta | `#1A1A2E` |
| Texto secundario | Gris azulado | `#5B5B6E` |
| Verde de paleta (acento secundario, opcional) | Verde menta fuerte | `#34D399` |

Tema visual: **fondo claro** (no dark mode) — se evaluó y descartó modo oscuro y switch día/noche por simplicidad de mantenimiento; el contraste vibrante lo aportan los acentos lila/menta/amarillo sobre blanco, no un fondo oscuro.

### Reglas de uso

- El badge amarillo es el ancla de reconocimiento de marca — no reemplazar por otro color sin razón fuerte (es heredado de la pieza de street art original).
- Lila y menta son intercambiables como acento secundario en el sitio (botones, íconos, highlights), pero no deben competir entre sí en la misma pieza salvo en el logo mismo.
- El negro tinta (`#1A1A2E`) se usa para contorno/sombra del logo y como color de texto — nunca un negro puro (`#000000`), para mantener coherencia con el resto de la paleta.
- Tipografía bubble/graffiti (estilo "Luckiest Guy" o equivalente vectorizado) solo para el wordmark/logo. El copy del sitio y redes usa una sans geométrica limpia y legible — el logo es la única pieza "graffiti", el resto de la marca debe leerse premium y profesional para no perder credibilidad B2B.

## Tono de comunicación

Premium pero accesible. La energía visual es urbana/vibrante (el logo), pero el copy vende un servicio serio (sistemas de venta con IA) — el balance es "calle con resultados", no "agencia corporativa genérica" ni "todo joda".
